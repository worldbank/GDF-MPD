# MNO Questionnaire

This section provides a questionnaire template that can be used to engage on a technical level with Mobile Network Operators (MNOs). The questionnaire allows to collect basic information on the following aspects:
- 📱 **Availability of Mobile Phone Data**
- 🏗️ **Data Infrastructure and Storage Capacity**
- 💻 **Computing Capacity**
- ⚙️ **Data Processing Capacity**
